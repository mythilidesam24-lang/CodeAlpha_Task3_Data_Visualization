# CodeAlpha Task 3 – Data Visualization

## Project Overview

This project was completed as part of the CodeAlpha Internship – Task 3: Data Visualization.

The main objective of this project is to transform raw data into meaningful visualizations and identify useful patterns and insights from the data.

## Project Title

**Titanic Dataset – Data Visualization and Insights**

## Objective

The objective of this project is to explore the Titanic dataset and use data visualization techniques to understand passenger information and survival patterns.

## Dataset

The Titanic dataset contains information about passengers, including:

* Passenger survival status
* Passenger class
* Gender
* Age
* Number of siblings and spouses
* Number of parents and children
* Passenger fare
* Embarkation details

## Tools and Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Google Colab
* GitHub

## Data Visualization

The project uses graphical representations to make the data easier to understand.

The visualizations include:

* Titanic Survival Count – Bar Chart
* Survival Distribution by Gender
* Passenger Class Analysis
* Age Distribution
* Fare Distribution
* Age vs Fare Analysis
* Fare Distribution by Passenger Class
* Correlation Analysis

## Key Insights

* The number of passengers who did not survive was higher than the number who survived.
* Survival outcomes differed between male and female passengers.
* Passenger class showed differences in survival outcomes.
* Passenger ages were distributed across different age groups.
* Passenger fares varied considerably between passenger classes.
* Visualizations helped identify relationships and patterns within the dataset.

## Methodology

The project followed these steps:

1. Imported the required Python libraries.
2. Loaded the Titanic dataset.
3. Examined the dataset structure and variables.
4. Checked the data for missing values.
5. Performed basic data cleaning.
6. Created different visualizations using Matplotlib and Seaborn.
7. Observed patterns and relationships in the visualizations.
8. Summarized the important findings.

## Project File

The complete analysis is available in:

`CodeAlpha_Task3_Data_Visualization.ipynb`

The notebook contains the Python code, executed outputs, and visualizations used for the analysis.

## Conclusion

This project demonstrates how data visualization can transform raw data into understandable visual information. Different charts and graphs were used to explore passenger characteristics and survival patterns in the Titanic dataset.

The project provided practical experience with Python-based data analysis and visualization using Pandas, Matplotlib, and Seaborn.
